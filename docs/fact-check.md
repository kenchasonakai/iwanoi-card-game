# 商品名と出来事の確認

ゲームに載せている商品名、酒米、受賞歴、イベント札の「もとになった話」が、岩瀬酒造の実際のものと合っているかを、2026年10月17日に Web で確かめた記録です。直したところは `src/game/cards.ts` と `design.md` に反映してあります。

## 結論

- 10種類の酒はすべて実在します。酒米も合っています。
- 直したのは次のところです。
  - 「秘蔵古酒二十年」は、正しくは「秘蔵古酒20年」。ラベルの縦書きでは、数字を横に並べて「20」と見せます。
  - 中汲みの正式名は「純米大吟醸・山田錦30%・中汲み」。「大吟醸 中汲み」と略すと、純米大吟醸とは別の種類の酒に見えるので、短い名前は「純米大吟醸 中汲み」にしました。
  - 山廃純米大吟醸のパーカーポイント95点は、年が資料で割れています（プレスリリースは2017年、公式の英語サイトと Wine Advocate の最初の日本酒レポートは2016年）。採点したのも、パーカー本人ではなく同誌の評価者です。札からは年を外し、「パーカーポイントで95点」としました。
  - 美酒アワードの正式名は「シェフが選ぶ美酒アワード2026」。主催の表記に合わせて「三つ星」にしました。
  - 南部の話は「南部杜氏」ではなく「南部から蔵人が来ている」（2024年の取材）。
  - クラウドファンディングは、秘蔵古酒20年ではなく、Makuake でのヴィンテージ古酒のセット。
- 気をつけること: 山廃純米大吟醸は、いまの蔵元直送ショップには載っていません。公式サイトの商品紹介に名前はありますが、リンク先は見つかりませんでした。
