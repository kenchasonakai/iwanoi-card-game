蔵元カードゲーム

岩の井の酒を造って売る、1人用のカードゲームです。素材を集め、人を雇い、酒を仕込んで出荷します。20ターン後の所持金が点数です。

このゲームについて

1人で10〜15分20ターンで1回が終わります
スマホの横画面ブラウザだけで動き、ログインもいりません
実在の酒が10種類札には受賞歴や味、合う料理を載せています

岩瀬酒造は千葉県御宿町の酒蔵で、銘柄は「岩の井」です。このゲームでは、その蔵元になって酒を造って売ります。造る酒は、i240 シリーズや山廃、古酒など、実際に売られている酒です。

ハッカソンでは6つの課題から1つを選びます。このゲームは「若い人が蔵のお酒を手に取る理由をつくる」に向けて作っています。遊ぶうちに酒の名前や受賞歴を覚え、終わったときの図鑑から蔵元直送ショップを見に行ける、という流れです。ゲームの中では購入や決済は扱いません。

設計の考え方

  • 酒に序列をつけない。どの酒も最初から造れます。素材が多い酒、時間がかかる酒と、得になる資源を酒ごとに変えています。
  • 人にも序列をつけない。役職の上下ではなく担当の違いです。得意な酒では1人で2マス埋め、ほかでは働けません。
  • 仕組みは2つだけ。「山札から引く」と「人を置く」です。交換、ライバル、品評会、季節は入れていません。
  • 実話に沿う。商品名、受賞歴、酒蔵の担当（酛屋など）、イベントの出来事の一部は、実際の蔵の話から作っています。実在の人の名前は使いません。

遊び方

はじめ

所持金12両、蔵人2人から始めます。手札は素材3枚、求人の場には3人が並びます。あとは毎ターン、右下の「次へ」で手順を進めるだけです。

1ターンの流れ

1ターンは7つの手順で進みます。画面の右下に手順の札があり、いまの手順で触る場所だけが光ります。雇う・買う・仕込むは、してもしなくてもかまいません。

  1. イベント

    出来事の札が1枚めくれて、すぐ効きます。山札から素材を2枚引きます。

  2. 雇う

    求人の場から、契約金を払って人を雇います。給料は毎ターン1人1両で、雇った人は手放せません。

  3. 買う

    取引先で素材を1ターン2枚まで買えます。酒の場の札で赤く縁どられた丸が、手札に足りない素材です。

  4. 仕込む

    酒の場の札を選び、素材を手札から払って自分の蔵に置きます（3つまで）。札をタップすると、味や受賞歴、いまの手札で仕込めるかが分かります。

  5. 置く

    雇っている人の駒をタップし、仕込み中の酒をタップして置きます。蔵人はどの酒でも1マス、酛屋・船頭・蔵守は得意な酒で2マス埋めます。駒を選ぶと、置いたときに埋まるマスが酒の札に出ます。

  6. 出荷

    右下の「仕込む」を押すと、置いた人の分だけおはじきが埋まり、全部埋まった酒が売れます。出荷の画面では、その酒の一言を大きく見せます。

  7. 給料

    雇っている全員に1人1両払って、次のターンへ。手札は5枚までで、超えたら選んで捨てます。

終わり方

ランクの目安（仮）は です。

札の種類

札は4種類です。山札から引く素材札、毎ターン1枚選ばれるイベント札、表向きに並ぶ酒の札と人材札です。数字はすべて仮で、遊びながら調整します。

酒の札（10枚）

酒の札はそのまま「持ち場」になり、その上に人を置いて仕込みを進めます。得意な担当の人は、その酒で1人2マス埋めます。

人材札（枚）

給料は全員、毎ターン1両です。札には架空の名前と一言を載せています。

素材の山札（枚）

手札に入れ、仕込みを始めるときに払います。取引先で買うこともできます。

イベント札（種類）

毎ターン最初に、重みに応じてランダムに1枚選ばれます。同じ札が何度も出ることがあります。悪い札は1ターン分くらいの損までにして、1枚で廃業しないようにしています。

細かい決まり

  • 同じ酒の値下がり。同じ酒の2回目の出荷は80%、3回目からは60%です。営業を雇っていると1段ゆるくなります。
  • 出荷の効果。「次に出荷する酒」の効果は1つだけ持てます。持っている間に出た効果は何も起きません。同じターンに2本以上出荷したら、いちばん高く売れる酒にかかります。
  • 売上の計算。札の売上 → 値下がり → イベントの倍率 → 足し引き → 切り捨て、の順です。
  • 置いた人。何人でも同じ酒に置けます。マスが余った分の働きは消えます。置いた人は、外すまで次のターンもそのまま置いておけます。埋めたマスは、人を外しても残ります。
  • 払った素材。山札から引いた素材は、払うと捨て札に置き、山札が尽きたら混ぜ直します。取引先で買った素材は、払ったら取引先に戻ります。
  • お金の使いどき。出荷で入ったお金は、同じターンの雇う・買うには使えません。
  • 仕込みをやめる。途中でやめられます。埋めたマスと払った素材は戻りません。
  • 求人の入れ替え。1両払うと、求人の場の3人を全部入れ替えられます（1ターン1回）。
  • 廃業。給料を払う時点でお金が足りないと廃業です。0両ちょうどなら続けられます。イベントで廃業にはなりません。

画面

数字の確かめ

ルールの数字は、画面と同じルールのモジュールを使う自動プレイで確かめています。雇い方の方針ごとに回ずつ遊ばせ、20ターン後の所持金と廃業の割合を出しました。方針は人より下手なので、数字の傾向を見るためのものです。表の「置ける力」は、置いたときに埋まるマスの合計（蔵人1、専門職2）で、その数まで雇うという意味です。

分かったこと

  • 誰も雇わないと平均94両前後で、ランクは C。専門職（酛屋・船頭・蔵守）と蔵人を雇うと150両前後まで伸び、A に届きます。雇うほど点は上がります。
  • その代わり、雇うほど廃業も増えます。最初の出荷の前に雇うと、序盤に給料が払えなくなりやすいです。
  • 麹屋・仕入れ係・帳場・営業は、1人足しても点が伸びません（雇わないより少し下がる）。効果が弱すぎるので、数字を見直す予定です。

作り

役割使うもの
描画、演出、入力Phaser 4（WebGL）
ビルドと開発サーバーVite
言語TypeScript
置き場所GitHub Pages。サーバーもログインも持たない
  • ルールと画面を分ける。ルールは Phaser に依存しないモジュールで、画面はその状態を描くだけです。同じモジュールを Node の自動プレイでも使うので、画面とシミュレーターでルールが食い違いません。このページの札の表も、同じデータから作っています。
  • 画面を撮って確かめる。Playwright でビルドしたゲームを開き、決まった手順でクリックして全場面と1ターンの動きを撮ります。ここの画像はすべてそれで撮ったものです。
  • スマホで読める文字。盤面は1280×720で設計し、iPhone の横画面では約0.54倍になります。遊ぶのに読む文字は15px以上にしています。
  • 生成AIの使いどころ。点数や売上の計算はすべてルールで決め、AIには任せません。応募者の架空の名前と一言を作るのに使う予定です。
